# не актуально

## 1. Архитектура и сетевая схема
Вся система взаимодействует асинхронно через центральный MQTT-брокер. Браузер (React) и системные службы (Python) общаются по разным портам одного брокера:
* **Порт 1883 (TCP):** Используется Python-симулятором для отправки показаний датчиков и приема RPC-команд управления исполнительными механизмами.
* **Порт 9001 (WebSockets):** Используется React-приложением напрямую из браузера для подписки на телеметрию в реальном времени и отправки команд.

## 2. Подготовка конфигурации Mosquitto
Начиная с версии 2.0, брокер Mosquitto по умолчанию запрещает внешние и анонимные подключения. Нам необходимо явно разрешить их и открыть порт для веб-сокетов.

1. Создайте в рабочей директории файл с именем `mosquitto.conf`.
2. Вставьте в него следующие конфигурационные строки:

```ini
# Стандартный порт для Python-скриптов и утилит
listener 1883 0.0.0.0
allow_anonymous true
# Порт для подключения веб-приложений (React) через сокеты
listener 9001 0.0.0.0
protocol websockets
# Включение детального логирования для упрощения отладки
log_type all
```

## 3. Развертывание брокера Mosquitto в Docker
1. Перед запуском удалите старые конфликтующие контейнеры, если они остались в системе:
```bash
docker rm -f mosquitto
```

2. Запустите контейнер с монтированием созданного конфигурационного файла:
- Для macOS / Linux / Git Bash:
```bash
docker run -d --name mosquitto \
  -p 1883:1883 -p 9001:9001 \
  -v $(pwd)/mosquitto.conf:/mosquitto/config/mosquitto.conf \
  eclipse-mosquitto
```

- Для Windows (PowerShell):
```bash
docker run -d --name mosquitto `
  -p 1883:1883 -p 9001:9001 `
  -v ${PWD}/mosquitto.conf:/mosquitto/config/mosquitto.conf `
  eclipse-mosquitto
```

3. Убедитесь, что контейнер успешно запущен:
```bash
docker ps
```
(В выводе должна присутствовать строка с контейнером mosquitto и статусом Up.)

## 4. Настройка и запуск Python-симулятора
Скрипт полностью автономен: он имитирует изменения температуры и влажности, не падает при потере сети (ждет восстановления соединения) и мгновенно реагирует на RPC-запросы.

1. Установите библиотеку для работы с MQTT:
```bash
pip install paho-mqtt
```

2. Запустить python файл greenhouse_sim.py

## 5. Проверка интеграции (Тестирование RPC)
1. Чтобы убедиться, что симулятор успешно отправляет команды, откройте новое окно терминала и сымитируйте получение команды сервером/интерфейсом:
```bash
docker exec -it mosquitto mosquitto_sub -h localhost -t "greenhouse/sensor_1/telemetry"
```
Появятся передаваемые значения. 

2. Чтобы убедиться, что симулятор успешно принимает команды и на их основании меняет внутренние параметры, откройте новое окно терминала и сымитируйте отправку команды сервером/интерфейсом:
```bash
docker exec -it mosquitto mosquitto_pub -h 127.0.0.1 -t "greenhouse/actuator_1/rpc/request" -m '{"action": "open"}'
```
Ожидаемый результат в окне Python-скрипта:
1. Появится запись: `[RPC] Получена команда: {'action': 'open'}`
2. Следом отобразится имитация работы: `[Имитация] Начинаем открывать форточку... -> [Имитация] Новый статус: ОТКРЫТА`
3. В следующей же строчке автоматической отправки телеметрии параметр `"window_state"` сменится на `"open"`.
